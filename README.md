# Живой перевод лекции: узбекский → русский (голос + субтитры)

Веб-страница, которая слушает звук компьютера, переводит речь на русский **голосом** и
одновременно показывает **крупные субтитры**, а в конце отдаёт конспект текстом.

Движок — `gemini-3.5-live-translate-preview` (Gemini Live API): потоковый аудио-перевод,
узбекский поддержан официально, задержка пара секунд, узбекско-русские переключения внутри
речи он держит (для лекций в Узбекистане это важно).

## Что нужно

* **Node.js 20+** — и всё. Зависимостей нет, `npm install` не требуется.
* API-ключ Gemini: https://aistudio.google.com/apikey (нужен проект с включённым биллингом —
  preview-модели на бесплатном тире обычно закрыты).
* У мамы: **Chrome или Edge** + наушники. Ставить ей ничего не нужно.

## Запуск

```bash
cd live-uz-ru
GEMINI_API_KEY=ваш_ключ ACCESS_CODE=придумайте_код node server.js
```

Открыть http://localhost:8080 — на localhost браузер разрешает захват звука без https.

Если сервер ответит, что не может выдать токен (в проекте нет доступа к ephemeral-токенам),
запустите с запасным режимом — ключ уйдёт прямо в страницу, для домашнего запуска это нормально:

```bash
GEMINI_API_KEY=ваш_ключ ALLOW_DIRECT_KEY=1 node server.js
```

Для мамы нужен **https** (по http с другого компьютера браузер звук не отдаст):

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8080   # выдаст временную https-ссылку
```

Насовсем — выложить папку на VPS или Railway/Render, задать переменные окружения и повесить
домен. В публичном варианте `ALLOW_DIRECT_KEY` не включать.

Переменные окружения:

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `GEMINI_API_KEY` | ключ Gemini, остаётся на сервере | обязательна |
| `ACCESS_CODE` | код, который мама вводит один раз | пусто (без проверки) |
| `ALLOW_DIRECT_KEY` | `1` — отдавать ключ странице, если токен не выдался | выключено |
| `TOKENS_PER_HOUR` | лимит сессий с одного IP в час | 40 |
| `PORT` | порт | 8080 |

Ключ в браузер не попадает: сервер меняет его на одноразовый короткоживущий токен
(`auth_tokens`, `uses: 1`), страница подключается к Live API уже им.

## Выложить в интернет (чтобы не нужен был VPN)

Страница может ходить в Gemini двумя путями:

1. **через этот сервер (релей)** — браузер соединяется со своим же сервером, а тот уже с Google.
   Регион тогда считается по хостингу, поэтому ни у кого не нужен VPN. Требуется модуль `ws`
   (`npm install`) — он есть в зависимостях и ставится сам при сборке Docker-образа;
2. **напрямую из браузера** — запасной путь, если релей недоступен. Тогда регион считается
   по тому, кто открыл страницу.

Россия в списке стран Gemini API отсутствует, Узбекистан — есть. Поэтому вариант с релеем
на зарубежном хостинге снимает вопрос для обеих сторон.

### Koyeb (бесплатно, без карты)

1. Залить эту папку в репозиторий на GitHub.
2. На koyeb.com создать Web Service → источник GitHub → сборка **Dockerfile**.
3. Регион — **Frankfurt**, порт **8080**, инстанс **Free**.
4. Переменные окружения: `GEMINI_API_KEY` (секрет), `ACCESS_CODE` (придумайте свой),
   `MAX_RELAYS=3`. `ALLOW_DIRECT_KEY` не задавать — ключ должен остаться на сервере.
5. Готовую ссылку вида `https://имя.koyeb.app` отправить маме.

### Google Cloud Run (нужна карта, зато щедрый бесплатный объём)

```bash
gcloud run deploy live-uz-ru --source . --region europe-west1 \
  --allow-unauthenticated --set-env-vars ACCESS_CODE=придумайте_код \
  --set-secrets GEMINI_API_KEY=gemini-key:latest
```

Render на бесплатном тарифе не подойдёт: WebSocket там только на платном.

Важно: на бесплатных тарифах сервис засыпает без нагрузки, первое открытие занимает
до минуты. Пусть мама открывает ссылку минуты за три до лекции.

## Как пользоваться

1. Открыть лекцию (Zoom, браузер, плеер), включить звук.
2. Надеть наушники — иначе перевод пойдёт обратно в микрофон/захват.
3. На странице нажать **▶ Начать**.
4. Chrome спросит, чем поделиться → **«Весь экран»** + галочка **«Также передать звук
   системы»**. Это работает и с Zoom-приложением, и с видео в браузере.
5. Пошёл голос перевода и субтитры. **💾 Сохранить конспект** выгружает `.txt` с
   переводом и оригиналом по времени.

Вариант «Микрофон» в списке источников — если лекцию слушают с колонок или телефона рядом.
Качество хуже, но работает без шаринга экрана.

## Что учтено внутри

* **Лимит сессии 15 минут** у Live API — страница сама переоткрывает соединение каждые
  12 минут и при любом обрыве, с перекрытием в 1.5 с, чтобы фраза не рвалась. Лекция на
  полтора часа идёт непрерывно.
* `echoTargetLanguage: true` — когда лектор переходит на русский, речь отдаётся как есть,
  а не переводится по кругу.
* Субтитры: `outputAudioTranscription` — русский текст, `inputAudioTranscription` — оригинал
  мелким шрифтом под ним (можно отключить галочкой).
* Оригинал звука в колонки не дублируется, эхо-петли нет.
* Конспект автосохраняется в `localStorage` на случай закрытой вкладки.

## Деньги

Примерно **$2.2 в час** по прайсу Live Translate (вход $3.5/1M токенов, выход $21/1M).
Полуторачасовая лекция ≈ $3.3. `ACCESS_CODE` и `TOKENS_PER_HOUR` стоят там, чтобы этот счёт
не рос без вашего ведома.

## Если что-то не так

| Симптом | Причина |
|---|---|
| «Звук не расшарен» | в окне выбора не поставлена галочка про звук системы |
| Субтитры идут, голоса нет | снята громкость или включена галочка «выключить голос перевода» |
| Перевод повторяет сам себя | мама без наушников, перевод попадает в захват |
| 403 при старте | не совпал код доступа |
| Ошибка модели/404 | preview-модель недоступна на вашем ключе — включите биллинг в AI Studio |
| Плохо на редких терминах | ограничение модели; текст конспекта потом можно почистить |

SDK подтягивается с `esm.sh` (`@google/genai@^1`). Если нужен полностью автономный хостинг —
соберите бандл локально (`npm i @google/genai` + esbuild) и замените импорт в `public/app.js`.
